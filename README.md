# BNN Power Tools

Landing page for BNN Power Tools: one platform that keeps match video and data together, with focused one-job instruments on top.

| Code | Instrument | Status | What it does |
|---|---|---|---|
| VID·01 | TouchlineFX | Preview | Clipping and advanced telestration with colour mapping, perspective and player tracking; data-annotated graphics |
| DAT·01 | MatchMorph | Experiment | Event data overlaid on match video as it happens; calculated metrics; aggregated and cumulative stats |
| VIS·01 | PitchScope | Preview | Tactics board based on real match situations |
| DIM·01 | HalfSpace | Experiment | Tracking data on top of video; real-time models such as pitch control and possession value |

Nothing is publicly released yet. **Preview** means usable by invitation; **Experiment** means a working prototype that may change. The platform and the next (developer) instrument are **concepts**. Names are working titles.

The site is a single static `index.html`, served with GitHub Pages from the `main` branch.
