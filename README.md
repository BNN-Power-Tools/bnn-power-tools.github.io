# BNN Power Tools

Landing page for BNN Power Tools: one platform that keeps match video and data together, with focused one-job instruments on top.

| Code | Instrument | What it does |
|---|---|---|
| VID·01 | TouchlineFX | Clipping and advanced telestration with colour mapping, perspective and player tracking; data-annotated graphics |
| DAT·01 | MatchMorph | Event data overlaid on match video as it happens; calculated metrics; aggregated and cumulative stats |
| VIS·01 | PitchScope | Tactics board based on real match situations |
| DIM·01 | HalfSpace | Tracking data on top of video; real-time models such as pitch control and possession value |

The platform and all instruments are **concepts**. Nothing is released yet, and the names are working titles.

The site is a single static `index.html`, served with GitHub Pages from the `main` branch.
