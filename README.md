# BNN Power Tools

Landing page for BNN Power Tools: one platform that keeps match video and data together, with focused one-job instruments on top.

| Code | Instrument | Job |
|---|---|---|
| VID·01 | VideoFX | Event data, drawn onto match video |
| DAT·01 | DataMorph | Data accumulating match by match |
| VIS·01 | PitchScope | Tactics boards for coaches and analysts |
| DIM·01 | Dimension | Data layers on the tactics board |
| TRN·01 | NuTool | Training drills designed from match video and data |

The platform and all instruments are **concepts**. Nothing is released yet, and the names are working titles.

The site is a single static `index.html`, served with GitHub Pages from the `main` branch.
